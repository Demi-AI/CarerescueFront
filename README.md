# CareRescue 前端

## 已完成

- 六個可操作頁面與班次詳細路由、找不到頁面處理。
- 今日缺口優先排序、資料同步動線。
- 新增請假、延誤、停服、送醫、需求變更事件。
- 規則篩選資格、性別、工時、前後班次及交通，展示排除原因。
- 規則模板方案說明，接受／改選候選人／拒絕，保存操作人與原因。
- 保存前後安排與站內模擬通知、回覆／失敗狀態。
- 從資料計算補位率、處理時間與補班分布。
- 瀏覽器 localStorage 保留資料，設定頁可還原示範。
- 共用元件、共用設計 token、CSS Modules、單一資料來源。

## 未完成

完整指這份前端示範可以獨立執行，不代表已完成實際長照派班產品。
所有個案、人員、交通時間、工時與技能條件都是合成設定。
目前沒有後端、登入／權限、真正通知、地圖 API、真實機構班表、生成式 AI 或多使用者同步。
排序是明確的示範權重，不是經驗證的最佳化或 AI 模型；規則不能視為法規合規判定。
只處理一日資料與單班補位，不會自動調整其他班次。延誤事件記錄分鐘並轉補位，未模擬人員恢復可用時間。
需求變更先建立待辦，尚未提供個案需求編輯；設定頁人員資料唯讀。
修改方案指改選其他通過規則的候選人，不支援任意指定時間或跳過必要條件。
localStorage 僅限同一個瀏覽器與網站來源，不適合真實個資；清除瀏覽器資料或換連接埠會失去／隔離資料。

- src/config/navigation.ts：側欄選單。
- src/components：共用按鈕、標題、標籤、卡片與確認視窗。
- src/layouts：共用側欄與內容版型。
- src/pages：六個功能頁面。
- src/styles/tokens.css：全站顏色與圓角。
- src/styles/global.css：表單、表格、面板等共用排版。
- 每個 *.module.css：該元件專用樣式。
